# Gear illustrations

These eighteen transparent 256px PNGs are exports of the game's native Godot
illustrations, not runtime texture dependencies. Names and source bosses are
listed in [GEAR.md](../../docs/GEAR.md).

Source: `scripts/rendering/actors/gear/`, composed through `relic_art.gd`.
Regenerate with Godot's `--script res://tests/rendered/gear_art_runner.gd`.
The same runner writes the labeled board to `artifacts/gear-lineup.png`.

Art direction: the user's September 7 portal screenshots, thick ink contours,
flat parchment/stone/wood/iron surfaces, colored insets, angular cuts, small
brass fittings and eighteen distinct object silhouettes. All art was authored
with the existing native drawing system; no image-generation model was used.
