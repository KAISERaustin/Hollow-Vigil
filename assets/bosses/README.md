# Approved boss sprite source

The user approved the detailed four-boss concept and explicitly requested restoring that quality instead of simplified native polygon drawings. Four sprites were prepared using the built-in imagegen tool with that concept as the sole visual reference. Generated September 5, 2026.

The generated RGB sources include a pale neutral presentation matte. `boss_matte.gdshader` removes that range during rendering, preserving the colored character interiors and black outlines. Boss sprite nodes are cached while visible and released when culled, and draw behind the parent battlefield's towers, projectiles and labels.
