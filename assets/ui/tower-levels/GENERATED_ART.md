# Illustrated level bubbles

Created with the built-in image_gen tool. Final assets: bubbles-1.png, bubbles-2.png, bubbles-3.png, bubbles-4.png. Each is a complete four-bubble state: one through four bright gold faceted bubbles, with illustrated muted stone-gray empty bubbles. No tower images are used.

The shared level indicator samples the four bubble regions and renders them with the standard 3-unit black frame and 4-unit corners. The source artwork is preserved; the UI mask excludes the generated backdrop. Regions are recorded in bubble-regions.json. Source PNGs are imported at 512px maximum width for small UI use.
