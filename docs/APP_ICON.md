# App icon

The app uses `icon.png`: an opaque 1024 × 1024 RGB PNG. `project.godot` selects `res://icon.png`; mobile export presets inherit this asset.

Updated September 9, 2026 at the user's request for a new design and a different base color. Deep plum replaces forest green. A single ivory watchtower combines an ochre crown and mint sanctuary crystal, framed by a parchment moon and purple landscape. The larger central silhouette improves launcher-size recognition.

The source is full bleed with no baked rounded corners, outer frame or transparency. This static branding asset is independent of gameplay drawing components. An app rebuild and installation are required to update phone home-screen icons; desktop import checks do not verify installed mobile builds.
