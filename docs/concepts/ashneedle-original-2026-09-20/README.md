# Ashneedle — The Arrow Watchtower

Original artwork family created September 20, 2026 with the built-in ImageGen
tool. The subject follows the supplied Ashneedle description: a fortified
archers' perch, tireless medieval watchmen, disciplined bowfire, lesser enemies
and wounded foes. No earlier tower artwork or concept was supplied as a visual
reference. Written image-generation and style instructions governed production.

This is a complete art concept set. It is not installed in the runtime catalog
and does not change tower names, attacks, statistics, save identities or balance.
The two specialization names below are descriptive art concepts.

| Sprite | Visible progression |
| --- | --- |
| `tier-1.png` | Stone watchpost, open timber perch, resting bow and arrow quiver |
| `tier-2.png` | Two stocked side firing galleries with load-bearing timber braces |
| `tier-3.png` | Iron-clad shelter above the central firing perch |

Tier 2 was generated by editing tier 1; tier 3 by editing tier 2. Each tier-4
branch independently edited the same completed tier 3. There is no tier 5.

## Placement and palette

All five transparent RGBA masters are **1254 × 1254** pixels, with core center
**x = 627** and shared visible ground anchor **y = 1128**. The tool returned a
1254-pixel source despite the initial prompt's 1024-pixel request; the source
was retained without resizing. All following edits use its actual dimensions.
Tier 1 was translated by (-4, -14) pixels before locking its placement. Its
contiguous subject was isolated with a mask to exclude disconnected background
residue, retaining the source alpha within the masked artwork.

`palette.json` records the 16 selected RGB colors and their roles. The common
tiers and Lastwatch use 15; Arrowstorm adds the reserved ochre color. Transparency
is separate. Nearest-palette conversion adds no dithering and preserves alpha.
Only additions are extracted from generated upgrades; repainted prior structure
is discarded. All **262,924 nontransparent base pixels** are copied exactly into
every finished sprite, including their original alpha. Earlier addition layers
are likewise preserved exactly at later tiers. New features occupy previously
empty canvas; the base and its shared material assignments never change.

## Sources, masks and verification

- `prompts.json`: complete prompts and generation provenance.
- `sources/`: untouched generated source files.
- `layers/` and `masks/`: retained upgrade artwork and explicit extraction masks.
- `assembly.json`: source-parent relationships and mask coordinates.
- `placement.json`: actual canvas and shared anchor coordinates.
- `validation.json`: saved-file palette, alpha, locked-layer and offset results.
- `family-review.png`: side-by-side review with fixed-scale thumbnails.
- `alignment-preview.webp`: all five sprites cycling at the same placement.

Rebuild and validate with Python, Pillow and NumPy:

```powershell
python docs/concepts/ashneedle-original-2026-09-20/build_family.py rebuild
```

The last pass restores tier-one material colors, sweeps all five sprites against
the allowed palette, saves and reopens them, and checks every nontransparent RGB
value. It confirms zero horizontal/vertical core offset, a common ground anchor,
exact prior-layer preservation, and unchanged alpha during the color sweep.
The set was visually inspected at full size and at the review's small scale.
These are artwork checks; no runtime or physical-device testing was performed.
