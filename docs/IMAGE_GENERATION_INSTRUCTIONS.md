# Image generation instructions

Keep the artwork simple and match Pickard's dark fantasy style.

1. **Use a maximum of 16 colors across the whole image family.** Choose one shared palette before generating. Keep the same dark material colors across every tier; upgrades must not make the tower lighter. Each image may use a subset of the palette.
2. **Keep every image centered and aligned.** Use the same canvas size, scale and ground anchor. Build upgrades on the same base so the tower does not shift when switching images. Do not center each tier by its flags or other added decorations.
3. **Use flags to distinguish tower tiers.** Tier 1 has no flag. Tier 2 adds a top flag. Tier 3 keeps it and adds a front banner. Both tier-four branches keep these and add a flag matching their specialization, such as ice or poison.

Preserve an approved design when making corrections: change only what was requested.

Reference: [Pickard artwork](../assets/ui/pickard-menu-background.png), [approved towers](concepts/gloamwatch/README.md), and [16-color palette](concepts/gloamwatch/PALETTE.md).
